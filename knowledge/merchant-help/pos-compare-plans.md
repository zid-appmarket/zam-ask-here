# المقارنة بين كاشير جو وكاشير برو

تشمل كاشير برو كل ما في كاشير جو. وتسرد هذه الصفحة ما تشترك فيه الباقتان وما تنفرد به كاشير برو، مجموعًا كما تجمعه لوحة التحكم. وتجد الجدول نفسه في **القنوات** > **نقاط البيع**: اضغط **مقارنة الباقات** ثم **عرض جميع الخصائص**.

## في الباقتين

تشمل كاشير جو وكاشير برو كلتاهما:

- **تسجيل الدخول والصلاحيات**: تسجيل دخول الكاشير (حساب التاجر)

- **عمليات البيع**: إنشاء فاتورة بيع؛ إضافة المنتجات إلى الفاتورة؛ إضافة العملاء والملاحظات إلى الفاتورة

- **الفواتير**: مشاركة الفاتورة بتقنية NFC

- **وسائل الدفع**: الدفع النقدي؛ تابي وتمارا (اشتر الآن وادفع لاحقا)؛ الدفع برابط الدفع؛ مزامنة طرق الدفع

- **إدارة عمليات البيع**: عرض تفاصيل عملية البيع؛ إرجاع المنتجات (كامل أو جزئي)

- **المنتجات**: البحث بالاسم أو SKU أو الباركود؛ التصفية حسب الفئة

- **التقارير والواجهات**: واجهة المبيعات المعلقة

- **الإعدادات**: عرض معلومات الحساب؛ مزامنة البيانات؛ مركز الدعم

## في كاشير برو وحدها

المجال الخصائص

**تسجيل الدخول والصلاحيات** تسجيل دخول الكاشير (حسابات المستخدمين الفرعية)؛ ربط المستخدمين أو الكاشير بالمخزون

**إدارة الجلسات** بدء الجلسة وإنهاؤها؛ سجل الجلسات

**عمليات البيع** حفظ الفاتورة لإتمامها لاحقًا؛ إنشاء طلبات توصيل أو طلبات إلكترونية؛ إنشاء طلبات الهدايا؛ إضافة الخصومات أو رموز الخصم؛ كسب نقاط الولاء واستبدالها؛ الدفع بأكثر من وسيلة في عملية واحدة؛ منتجات بسعر متغير

**الفواتير** إرسال الفاتورة بالرسائل النصية؛ طباعة الفاتورة؛ تخصيص قوالب الفواتير

**وسائل الدفع** الدفع بالبطاقة أو أجهزة نقاط البيع؛ تكامل مع NearPay؛ إضافة أو إدارة طرق دفع مخصصة

**المنتجات** تحديد قنوات عرض المنتج؛ البحث بين المخازن

**الطلبات** الشراء أونلاين والاستلام من المتجر؛ الإرجاع في المتجر للطلبات الإلكترونية

**التقارير والواجهات** واجهة التقارير؛ طباعة تقارير المبيعات والمنتجات؛ تقارير المبيعات والمدفوعات؛ واجهة الطلبات

**الإعدادات** ربط الأجهزة (الباركود والطابعة)؛ ربط أجهزة الدفع؛ تخصيص صفحة المنتجات وترتيبها

**طلبات المخزون** إنشاء طلب مخزون؛ تعديل طلب مخزون؛ استلام طلب مخزون

**مواقع المخزون** موقع مخزون إضافي لكل كاشير

هل اخترت؟ فعّل كاشير جو مجانًا، أو اشترك في كاشير برو .
