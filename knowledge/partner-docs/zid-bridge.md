> Zid Bridge Tool - Zid Docs
**Not for public apps in production.** Zid Bridge is a testing and private-app tool. **Any public app submitted for review with Zid Bridge URLs registered as its redirect or callback URL will be rejected.** A public app must implement the OAuth flow on its own server — see Public Apps OAuth Requirements (https://docs.zid.sa/oauth-requirements).
