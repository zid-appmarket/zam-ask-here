# Format examples — not company information

Everything in this directory is **illustrative only**. The loader skips any path
whose name starts with `_`, so nothing here is ever indexed or quoted by the
agent.

`example-document.md` shows a well-formed bilingual document with the structure
that retrieves well. Every value in it is a placeholder: `<REPLACE: …>`. Do not
copy it into a real directory until every placeholder is replaced with a fact
the document's owner has confirmed.
